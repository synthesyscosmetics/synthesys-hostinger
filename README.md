# SYNTHESYS — site institucional

Site estático em HTML, CSS e JavaScript, recuperado do modelo aprovado.

## Arquivos

- `index.html`: conteúdo e estrutura.
- `style.css`: aparência e adaptação às telas.
- `app.js`: menu e abas das áreas de atuação.
- `assets/`: identidade e imagens.
- `robots.txt` e `sitemap.xml`: descoberta por mecanismos de busca.

## Visualização local

Execute `python -m http.server 8000` na pasta do projeto e acesse http://localhost:8000.

## Hostinger

Este projeto não precisa de instalação de pacotes nem compilação. Na hospedagem convencional, publique o conteúdo desta pasta em `public_html`, com `index.html` diretamente nessa pasta. Não envie a pasta `.git`.

Se o repositório estiver vinculado como aplicação Node.js, confirme essa configuração antes de publicar: os arquivos atuais destinam-se à hospedagem estática, sem servidor Node.js.

## Antes do lançamento

Confirme a conexão do domínio e o certificado HTTPS no painel. Adicione os dados reais de contato e revise os textos comerciais. As imagens de produtos são conceituais. A versão inicial preserva o conteúdo e as interações do modelo, sem formulário de envio ou banco de dados.
